## About

**Asignatura:** Planificación Automática · UAH GII · Curso 2026-27 · 3er Curso

Automated planning and scheduling in AI: how an agent finds a sequence of actions to reach a goal from an initial state, and how that search is made tractable with heuristics and structure.

---

## Topics covered

| Block | Content |
|-------|---------|
| Classical Planning | State-space and plan-space search, STRIPS representation, PDDL domain and problem modelling |
| Heuristics | Planning graphs, relaxed problems, admissible and inadmissible heuristics |
| Hierarchical Planning | HTN decomposition, task networks, method libraries |
| Extensions | Temporal planning, resource constraints, planning under uncertainty |
